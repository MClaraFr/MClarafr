### ◈ Featured project

#### 🌾 Margeo

**Agricultural management system**

Uma PWA desenvolvida para auxiliar no gerenciamento de atividades agrícolas, centralizando informações e facilitando o acompanhamento dos custos por área.

| Funcionalidade | Descrição                          |
| -------------- | ---------------------------------- |
| Talhões        | Gerenciamento de áreas agrícolas   |
| Produtos       | Cadastro e controle de produtos    |
| Aplicações     | Registro e histórico de aplicações |
| Custos         | Acompanhamento de gastos por área  |

**Project stack**

`Flutter` `Laravel` `SQL` `Docker`

\<details>
\<summary>\<strong>⌕ More about the project\</strong>\</summary>

O Margeo reúne uma aplicação Flutter, uma API desenvolvida com Laravel e uma estrutura de banco de dados para centralizar os registros agrícolas.

O objetivo é facilitar o controle das operações e transformar os dados registrados em informações úteis para o acompanhamento da propriedade.
