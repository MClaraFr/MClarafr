## ◈ Featured project

### 🌾 Margeo

**Agricultural management system**

PWA desenvolvida para auxiliar no gerenciamento de atividades agrícolas, centralizando informações e facilitando o acompanhamento dos custos por área.

**Core features**
- Gerenciamento de talhões
- Cadastro e controle de produtos
- Registro e histórico de aplicações
- Controle de consumo e custos agrícolas

**Project stack**

`Flutter` `Laravel` `SQL` `Docker`

<details>
<summary><strong>⌕ Technical overview</strong></summary>

O Margeo reúne uma aplicação Flutter, uma API desenvolvida com Laravel e um banco de dados para centralizar os registros agrícolas.

O sistema utiliza regras de negócio para processar informações de aplicações e calcular custos por área.

</details>
